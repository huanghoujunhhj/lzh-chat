# 刘梓菡 · AI 聊天

一个现代化的 AI 聊天网页应用，角色为「刘梓菡」——初二升初三的初中生，数学课代表。

## 特性

- 💬 **历史会话列表** — 侧边栏自动管理所有会话，标题取自首条用户消息前 15 字
- ➕ **新建会话** — 桌面端顶部 + 按钮，移动端侧边栏内 + 按钮
- 💾 **会话持久化** — localStorage 存储（key: `chat-sessions-lzh`），刷新自动恢复
- 🗑️ **删除会话** — 鼠标悬停显示删除按钮，删完最后一个自动新建
- 📱 **响应式 UI** — 桌面端侧边栏常驻，移动端汉堡菜单唤出（带半透明遮罩）
- 🧠 **上下文对话** — 每次发送消息给 AI 时附带历史，保持对话连贯性
- 🧹 **清空对话** — 一键清空所有历史记录
- 🤖 **本地智能 Bot** — 默认基于刘梓菡人设的本地回复，永久可用、零依赖
- 🌐 **可选真实 AI** — 设置面板可填入 OpenAI 兼容 API，启用 GPT 等真实模型

## 本地运行

任意静态服务器即可，例如：

```bash
# Python
python -m http.server 8000

# Node
npx serve .
```

然后浏览器访问 `http://localhost:8000`。

## 部署到 GitHub Pages

1. 创建一个新仓库（如 `lzh-chat`）
2. 把这 3 个文件（`index.html`、`style.css`、`app.js`）推上去
3. 仓库 Settings → Pages → 选择 `main` 分支根目录 → 保存
4. 访问 `https://<你的用户名>.github.io/lzh-chat/`

## 真实 AI 配置

设置面板里填入：

- **API Base URL**：例如 `https://api.openai.com/v1` 或你的 Cloudflare Worker 中转地址
- **API Key**：你的 OpenAI（或兼容服务）密钥
- **模型**：如 `gpt-3.5-turbo`、`gpt-4` 等
- **系统提示词**：默认已填刘梓菡人设，可自定义

⚠️ API Key 仅保存在你本地浏览器，不会上传服务器。若遇跨域问题，可配合 Cloudflare Worker 中转。

- **身份**：初二升初三的初中生，数学课代表
